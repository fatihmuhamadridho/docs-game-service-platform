# Go Authentication Routes — Source Audit

Status: implementation evidence, not approved target contract. Source: `go-game-service-platform/internal/controller/http/auth_http.go`, `internal/controller/auth.go`, and `internal/view`. All responses use `view.WriteJSON` envelope `{status:{code,message},data}`. Common decoder limits body to 1 MiB, rejects unknown JSON fields and trailing JSON values. There is no idempotency-key handling. Rate limiting applies only to login, register, forgot-password, and reset-password handlers, with exact thresholds and failure behavior below.

## Cookie and error contract

Customer cookie names: `__Host-jokihub-session`, `__Host-jokihub-refresh`; hint `jokihub-customer-refresh-present`. Admin names: `jokihub-admin`, `jokihub-admin-refresh`; hint `jokihub-admin-refresh-present`. Access TTL 900 seconds; refresh TTL seven days. Access/refresh HttpOnly; hints script-readable. Customer SameSite Lax; admin Strict. `Secure` is always true for customer and production-only for admin. Rate-limit outcomes are implemented by `enforceRateLimit` / `rateLimitHit` in `internal/controller/http/auth_http.go`: HTTP 429, `AUTB01002`, computed positive-seconds `Retry-After`, `Cache-Control:no-store`; limiter configuration/storage failure returns HTTP 503 `AUTT03001`. These apply only to login, register, forgot-password, and reset-password because only those handlers call the limiter. Logout, refresh-token, and session routes do not call it.

## Exact rate limits and closure notes

Source `rateLimitConfig` in `internal/controller/http/auth_http.go`: login 100/IP and 10/IP+identifier per 15 minutes; register 20/IP and 3/IP+email per hour; recovery 20/IP and 5/IP+subject per hour. Enforcement is invoked in login, register, forgot-password, and reset-password; not invoked in logout, refresh, or session. Exceeded limits return 429 `AUTB01002`, `Retry-After`, and no-store; limiter storage/config failure returns 503 `AUTT03001`. IP comes from `X-Real-IP`, then first `X-Forwarded-For`, then `unknown`; IP/subject keys are HMAC-derived with `JWT_SECRET` (minimum 32 chars). `RegisterAuthRoutes` accepts `EmailSender`, but registration does not send mail. No route implements email verification. Reset flow is one-use, expires after 30 minutes, hashes password bcrypt cost 12, revokes customer refresh sessions (`internal/controller/auth.go`). These are implementation facts; IFAs' alternate verification/session policy remains proposed target.
