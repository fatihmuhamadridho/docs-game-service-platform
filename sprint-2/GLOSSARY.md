# Glosarium Sprint 2 — Katalog, Pengaturan, dan Audit

Glosarium ini menjelaskan istilah bersama yang digunakan dalam BRD, HLD Sprint 2, ERD layanan/kategori/pengaturan/audit, serta IFA publik dan Admin Dashboard Sprint 2. Istilah khusus endpoint atau fitur dijelaskan lebih rinci pada dokumen solutioning terkait; keputusan yang masih terbuka tercatat pada [register keputusan Sprint 2](./solutioning/open-decisions.md).

| Istilah                                                          | Definisi                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Admin Dashboard                                                  | Antarmuka administratif JokiHub untuk administrator terautentikasi dan berwenang.                                                                                                                                                                                                             |
| Activity Log (Riwayat Aktivitas)                                 | Tampilan atau consumer untuk membaca catatan aktivitas. Keberadaannya tidak dengan sendirinya menetapkan taxonomy, cakupan, atau penyimpanan audit event BR-022.                                                                                                                              |
| API (Application Programming Interface)                          | Kontrak yang memungkinkan aplikasi storefront atau dashboard meminta data dan tindakan dari backend.                                                                                                                                                                                          |
| Append-Only                                                      | Pola pencatatan yang menambahkan event tanpa mengubah atau menghapus event melalui alur aplikasi normal; retensi memerlukan kebijakan terpisah.                                                                                                                                               |
| Audit Event                                                      | Catatan server-side tentang aksi admin, aktor, target, hasil, dan waktu; field sensitif harus diizinkan secara eksplisit dan diredaksi.                                                                                                                                                       |
| BSON (Binary JSON)                                               | Format dokumen biner yang digunakan MongoDB untuk menyimpan dan mengirim data bertipe.                                                                                                                                                                                                        |
| BRD (Business Requirements Document)                             | Dokumen kebutuhan bisnis yang menetapkan tujuan, cakupan, aturan, dependensi, serta kebutuhan tingkat bisnis.                                                                                                                                                                                 |
| BR-ID (Business Requirement Identifier)                          | Label kebutuhan bisnis untuk traceability. Jangan gunakan nomor BR sebagai key lintas sprint sampai canonical register dikonfirmasi; repo saat ini memuat makna berbeda untuk BR-003–BR-008 (D-17).                                                                                           |
| CDN (Content Delivery Network)                                   | Jaringan distribusi konten yang dapat menyimpan dan menyajikan salinan respons dari lokasi tepi; kebijakan cache Sprint 2 masih TBD.                                                                                                                                                          |
| Authentication (Autentikasi)                                     | Pemeriksaan identitas pengguna atau sistem sebelum akses diberikan.                                                                                                                                                                                                                           |
| Authorization (Otorisasi)                                        | Pemeriksaan apakah identitas yang telah diautentikasi memiliki izin untuk melakukan aksi atau membaca resource tertentu.                                                                                                                                                                      |
| Cookie Session                                                   | Kredensial sesi browser yang dikirim otomatis ke server; endpoint cookie-authenticated memerlukan perlindungan CSRF dan pemeriksaan Origin.                                                                                                                                                   |
| Cache Invalidation (Invalidasi Cache)                            | Penghapusan atau pembaruan data cache agar konsumen membaca versi katalog atau pengaturan yang sesuai kebijakan freshness.                                                                                                                                                                    |
| Catalog (Katalog)                                                | Kumpulan game, kategori layanan, dan layanan yang dapat ditemukan; eligibility pembelian ditentukan oleh aturan bisnis yang disetujui.                                                                                                                                                        |
| Eligibility (Kelayakan Katalog)                                  | Predicate yang menentukan apakah game, kategori, atau layanan ditampilkan atau tersedia pada konteks tertentu. Predicate storefront, admin, dan order dapat berbeda; aturan final menunggu D-02/D-14.                                                                                         |
| DB (Database)                                                    | Penyimpanan terkelola untuk data aplikasi; engine dan schema fisik Sprint 2 harus mengikuti keputusan arsitektur/data.                                                                                                                                                                        |
| Go                                                               | Bahasa pemrograman backend API pada baseline arsitektur proyek; catatan route Sprint 2 di repo merupakan dokumentasi kontrak dan bukan verifikasi kode saat ini.                                                                                                                              |
| CPU (Central Processing Unit)                                    | Sumber daya pemrosesan yang target pemakaian produksinya perlu ditetapkan melalui estimasi kapasitas dan/atau pengujian beban.                                                                                                                                                                |
| CRUD (Create, Read, Update, Delete)                              | Operasi dasar untuk membuat, membaca, memperbarui, dan menghapus data.                                                                                                                                                                                                                        |
| CSRF (Cross-Site Request Forgery)                                | Serangan yang mencoba membuat browser mengirim request terautentikasi dari situs lain; token CSRF dan validasi Origin membantu mencegahnya.                                                                                                                                                   |
| Decimal128                                                       | Tipe angka desimal presisi tinggi yang didukung MongoDB; representasi harga API tetap perlu keputusan lintas sistem.                                                                                                                                                                          |
| DTO (Data Transfer Object)                                       | Struktur data untuk membawa nilai antar lapisan atau batas layanan; bukan dengan sendirinya schema penyimpanan.                                                                                                                                                                               |
| ERD (Entity-Relationship Diagram)                                | Representasi entitas penyimpanan dan hubungan di antaranya; engine dan model fisik Sprint 2 masih perlu dikonfirmasi.                                                                                                                                                                         |
| Envelope Response API                                            | Bentuk response target Sprint 2 mengikuti baseline Sprint 1: `code`, `message`, dan `data` berada di root. Untuk list, `data` berupa array dan `pagination` menjadi sibling di root; untuk detail, object resource langsung berada di `data`. Error tanpa payload mengembalikan `data: null`. |
| Exposure (Paparan)                                               | Istilah yang harus dibedakan menurut konteks: data exposure/projection menentukan field yang boleh disajikan; deployment/network exposure menentukan siapa yang dapat menjangkau endpoint. Public settings dan batas jaringan perlu keputusan terpisah (D-09/D-11).                           |
| FK (Foreign Key)                                                 | Istilah model relasional untuk kunci yang merujuk ke entitas lain; ERD MongoDB Sprint 2 memakai application references dan tidak menjanjikan constraint FK fisik.                                                                                                                             |
| Fixed-Price Service (Layanan Harga Tetap)                        | Layanan dengan harga final yang ditetapkan sistem dan dapat digunakan dalam perhitungan transaksi setelah kebijakan harga disetujui.                                                                                                                                                          |
| HLD (High-Level Design)                                          | Dokumen arsitektur tingkat tinggi yang menjelaskan komponen, deployment, integrasi, dan alur utama suatu cakupan.                                                                                                                                                                             |
| HTTP (Hypertext Transfer Protocol)                               | Protokol aplikasi untuk pertukaran request dan response web.                                                                                                                                                                                                                                  |
| HTTPS (Hypertext Transfer Protocol Secure)                       | HTTP yang dilindungi oleh TLS untuk komunikasi jaringan.                                                                                                                                                                                                                                      |
| HTML (HyperText Markup Language)                                 | Bahasa markup untuk menyusun konten halaman web; konten yang disimpan dan dirender perlu validasi serta sanitasi yang sesuai.                                                                                                                                                                 |
| IFA (Interface Agreement)                                        | Dokumen kontrak antarmuka yang menetapkan perilaku endpoint, input, output, validasi, error, dan pengujian.                                                                                                                                                                                   |
| IANA (Internet Assigned Numbers Authority)                       | Organisasi yang memelihara registri teknis internet, termasuk basis pengenal zona waktu yang digunakan oleh aturan timezone.                                                                                                                                                                  |
| IDR (Indonesian Rupiah)                                          | Kode mata uang rupiah Indonesia; penggunaan dan presisi nilai harga Sprint 2 tetap menunggu keputusan pricing.                                                                                                                                                                                |
| IDOR (Insecure Direct Object Reference)                          | Kelemahan akses ketika identifier objek dapat dimanipulasi untuk membaca atau mengubah resource tanpa otorisasi yang semestinya.                                                                                                                                                              |
| IP (Internet Protocol)                                           | Protokol pengalamatan dan pengiriman paket jaringan; alamat IP dapat menjadi data pribadi dan perlu perlindungan sesuai kebijakan.                                                                                                                                                            |
| ISO (International Organization for Standardization)             | Organisasi standardisasi yang menerbitkan ISO 4217 untuk kode mata uang dan ISO 8601 untuk format tanggal/waktu yang digunakan pada kontrak Sprint 2.                                                                                                                                         |
| JSON (JavaScript Object Notation)                                | Format teks untuk pertukaran data terstruktur yang digunakan pada contoh payload API.                                                                                                                                                                                                         |
| Maintenance Mode (Mode Pemeliharaan)                             | Pengaturan yang mengubah ketersediaan storefront saat pemeliharaan; cakupan blokir dan perilaku pengecualian perlu dikonfirmasi.                                                                                                                                                              |
| Member                                                           | Akun pelanggan untuk fitur storefront/member; terpisah dari akun administrator.                                                                                                                                                                                                               |
| Mock Data (Data Mock)                                            | Data contoh atau simulasi pada UI; tidak membuktikan data persisten, aturan bisnis, maupun nilai produksi yang disetujui.                                                                                                                                                                     |
| MongoDB                                                          | Database dokumen yang didokumentasikan pada baseline Sprint 1 untuk Go API; schema dan index fisik Sprint 2 tetap menunggu keputusan.                                                                                                                                                         |
| NFT (Non-Functional Testing)                                     | Pengujian karakteristik non-fungsional seperti kapasitas, performa, dan stabilitas; ruang lingkup dan target Sprint 2 belum disetujui.                                                                                                                                                        |
| Next.js                                                          | Framework aplikasi web yang digunakan untuk storefront dan Admin Dashboard platform.                                                                                                                                                                                                          |
| PII (Personally Identifiable Information)                        | Informasi yang dapat mengidentifikasi atau menghubungi individu, seperti nama, email, nomor telepon, atau alamat IP; akses, redaksi, dan retensinya harus dikendalikan.                                                                                                                       |
| PK (Primary Key)                                                 | Label kunci identifikasi logis pada ERD; dokumen MongoDB tetap memiliki `_id`, sedangkan kebutuhan identifier tambahan dan mapping fisiknya masih TBD.                                                                                                                                        |
| Permission Catalog / Grant                                       | Katalog system-managed berisi key permission aktif yang dapat diberikan pada role; route harus memeriksa key yang disetujui. Penambahan key dan mapping role untuk capability Sprint 2 masih menunggu keputusan D-18.                                                                         |
| Pentest (Penetration Testing)                                    | Pengujian keamanan terkontrol yang mencoba mengeksploitasi kelemahan dalam cakupan yang disetujui.                                                                                                                                                                                            |
| Pagination                                                       | Metadata pembagian hasil list per halaman. Pada target IFA Sprint 2, `pagination` berada di root sejajar dengan `data`; nama dan makna field ditetapkan per endpoint.                                                                                                                         |
| Platform Settings (Pengaturan Platform)                          | Konfigurasi umum platform seperti identitas/kontak, preferensi regional, mode pemeliharaan, dan ketersediaan registrasi; field final dan exposure publik masih perlu disetujui.                                                                                                               |
| Quote-Required Service (Layanan yang Memerlukan Penawaran Harga) | Layanan tanpa harga final yang disetujui saat katalog dibaca; transaksi tidak boleh memakai nominal rekaan dan memerlukan alur penawaran tersendiri.                                                                                                                                          |
| RBAC (Role-Based Access Control)                                 | Model kontrol akses yang mengelompokkan izin ke role dan memberikan role kepada akun admin.                                                                                                                                                                                                   |
| REST (Representational State Transfer)                           | Gaya arsitektur API yang menggunakan resource dan semantik HTTP; istilah ini tidak menetapkan sendiri kontrak status atau payload Sprint 2.                                                                                                                                                   |
| Service (Layanan)                                                | Penawaran terkait game yang dapat memiliki kategori, status ketersediaan, estimasi, dan skema harga; detail final mengikuti keputusan produk.                                                                                                                                                 |
| Service Category (Kategori Layanan)                              | Pengelompokan layanan untuk navigasi dan pengelolaan katalog; aturan status, urutan, dan relasi masih perlu disepakati.                                                                                                                                                                       |
| Service Count (`serviceCount`)                                   | Jumlah layanan terkait yang ditampilkan dalam konteks tertentu. Usulan admin menghitung layanan non-deleted termasuk inactive; proyeksi publik menghitung layanan yang eligible menurut aturan game/kategori aktif. Predicate final masing-masing konteks menunggu keputusan D-14.            |
| SEO (Search Engine Optimization)                                 | Praktik meningkatkan keterindeksan dan penyajian halaman pada mesin pencari; kebutuhan halaman publik Sprint 2 masih bergantung pada keputusan scope.                                                                                                                                         |
| SLA (Service-Level Agreement)                                    | Target layanan terukur dengan cakupan dan kondisi ukur yang disepakati. IFA Sprint 2 mencantumkan baseline angka turunan Sprint 1 sebagai usulan; persetujuan target Sprint 2 masih TBD (D-12).                                                                                               |
| SMTP (Simple Mail Transfer Protocol)                             | Protokol pengiriman email; penggunaan layanan email untuk workflow Sprint 2 belum disetujui.                                                                                                                                                                                                  |
| SRE (Site Reliability Engineering)                               | Disiplin rekayasa untuk keandalan layanan, operasi, kapasitas, dan pengukuran target layanan.                                                                                                                                                                                                 |
| Soft Delete (Penghapusan Lunak)                                  | Penandaan record sebagai terhapus yang biasanya mengecualikannya dari operasi normal. Istilah ini tidak otomatis berarti restore didukung atau menetapkan retensi; lifecycle Sprint 2 masih menunggu persetujuan.                                                                             |
| SVG (Scalable Vector Graphics)                                   | Format gambar vektor yang digunakan sebagai diagram arsitektur Sprint 2.                                                                                                                                                                                                                      |
| Sprint 2                                                         | Kelompok delivery usulan untuk kategori/layanan, pengaturan platform, fondasi pencatatan audit, dan sebagian informasi publik; urutan tidak menjadi komitmen sebelum disetujui.                                                                                                               |
| TBD (To Be Determined)                                           | Nilai atau keputusan yang belum tersedia dan harus dikonfirmasi oleh pemilik yang berwenang.                                                                                                                                                                                                  |
| TLS (Transport Layer Security)                                   | Protokol kriptografi yang melindungi komunikasi jaringan; versi dan konfigurasi operasional mengikuti standar deployment.                                                                                                                                                                     |
| TPS (Transactions Per Second)                                    | Jumlah transaksi yang diproses per detik; target beban Sprint 2 harus bersumber dari forecast dan strategi uji.                                                                                                                                                                               |
| TTL (Time To Live)                                               | Durasi suatu nilai atau cache dianggap berlaku sebelum kedaluwarsa; durasi cache Sprint 2 belum disepakati.                                                                                                                                                                                   |
| UI (User Interface)                                              | Antarmuka yang digunakan seseorang untuk berinteraksi dengan aplikasi, seperti storefront atau Admin Dashboard.                                                                                                                                                                               |
| URL (Uniform Resource Locator)                                   | Alamat yang menunjukkan lokasi resource, termasuk skema/protokol dan path.                                                                                                                                                                                                                    |
| UTC (Coordinated Universal Time)                                 | Acuan waktu standar untuk timestamp sistem; penyimpanan dan konversi lokal mengikuti kontrak yang disetujui.                                                                                                                                                                                  |
| UX (User Experience)                                             | Pengalaman pengguna saat mencapai tujuan melalui interaksi dengan produk atau layanan.                                                                                                                                                                                                        |
| VUser (Virtual User)                                             | Pengguna virtual konkuren dalam pengujian beban; jumlah target perlu didasarkan pada forecast trafik.                                                                                                                                                                                         |
| VA (Vulnerability Assessment)                                    | Penilaian sistematis untuk mengidentifikasi kerentanan keamanan; scope Sprint 2 bergantung pada exposure dan keputusan pengujian.                                                                                                                                                             |
| Vercel                                                           | Platform deployment yang digunakan aplikasi Next.js dan backend API pada baseline proyek; topologi Sprint 2 dan batas runtime tetap perlu diverifikasi.                                                                                                                                       |
| Version / Optimistic Concurrency (Versi / Konkruensi Optimistis) | Pemeriksaan versi resource sebelum perubahan agar pembaruan lama tidak menimpa perubahan yang lebih baru; mekanisme settings Sprint 2 masih TBD.                                                                                                                                              |
| XSS (Cross-Site Scripting)                                       | Kerentanan yang memungkinkan skrip tak tepercaya dijalankan dalam konteks browser pengguna lain.                                                                                                                                                                                              |
