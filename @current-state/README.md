# Current-State References

This folder contains documents that describe features and behavior already present in the application. Use them as references when reviewing existing behavior or preparing changes.

## Contents

- `acceptance-criteria/` — current feature behavior and acceptance criteria.
- `solutioning/` — current API contracts and backend flows.

## Guidance

- Treat these documents as descriptions of the current state; do not assume they describe proposed changes.
- Check that a reference applies to the feature and version being discussed.
- When a change is approved, update or add the appropriate project document outside this folder, then update the current-state reference when the new behavior is delivered and verified.
